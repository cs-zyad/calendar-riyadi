# تقويم نادي ريادة الأعمال

تقويم شهري عربي (RTL) لفعاليات نادي ريادة الأعمال للفصل الأول 1448هـ (23 أغسطس 2026 – 16 يناير 2027).

- تقويم ميلادي مع الأسابيع الدراسية وعرض يومي للفعاليات
- إضافة وتعديل وحذف الفعاليات (بكلمة سر)، وأنواع مخصصة بألوان
- خانتا «منفذة» و«تعبئة نموذج التوثيق»
- وضع فاتح (بيج) وغامق

الصفحة `index.html` تعمل كـ Artifact على claude.ai، والفعاليات محفوظة في قاعدة بيانات الصفحة وليست في هذا الملف.
